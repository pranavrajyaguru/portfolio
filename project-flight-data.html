Flight Data Analysis & Anomaly Detection

Planned software to turn logs from the Piper aircraft into signals and events that can be explored after a flight.

Flight log visualisationImage placeholder ? Interface not yet developed

Project intent

Understand the flight. Investigate the unusual.

I want to develop software to analyse logs from the Piper RC aircraft, visualise recorded signals and identify unusual events for closer inspection. This is a planned project: the functionality below describes the intended scope, with no completed software features or measured detection results yet.

Intended functionality

A path from recorded logs to reviewable events.

01

Analyse aircraft logs

The software would load logs from the Piper and organise the available time-based signals for analysis. The supported signals will depend on the recorded data.

02

Visualise signals

The intended interface would plot signals over time and allow selected intervals to be examined together to understand changes during a flight.

03

Identify unusual events

I plan to explore ways to flag unexpected changes or patterns and show the surrounding signals so that each event can be reviewed in context.

04

Evaluate detections

A future evaluation would compare flagged events with reviewed flight logs, investigate false alarms and missed events, and document the limits of the approach.

Development plan

Start with the aircraft?s recorded data.

The first step will be to inspect representative Piper logs and define the initial signals and events to investigate. Log visualisation would precede anomaly-detection experiments. The detection method and evaluation criteria remain to be selected once suitable data is available.

Connected aircraft

Built around the Piper integration project.

The planned data source is the existing Piper RC aircraft currently undergoing ArduPilot and Pixhawk integration. The hardware work covers controller, antenna and battery mounts, internal space, weight distribution and centre of gravity.
